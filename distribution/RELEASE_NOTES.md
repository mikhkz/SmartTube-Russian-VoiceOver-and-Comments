# SmartTube Russian Voice Over · 32.68-vot.1

SmartTube 32.68 Stable со встроенной русской озвучкой Яндекса.
Нативный протокол обновлён по VOT 1.12.3 / vot.js 3.2.0,
компонент Яндекса 26.10.0.1796.

- Обычные и живые голоса, кнопка перевода и автоперевод.
- Раздельная громкость оригинала и озвучки, усиление перевода до 150%.
- Синхронизация с паузой, перемоткой и скоростью.
- Загрузка исходного аудио через SABR по запросу Яндекса.
- Перевод иностранных комментариев на русский.
- Имя приложения SmartTube VOT и отдельный канал обновлений.

Для большинства устройств выбирайте `universal.apk`; для 32-битных телевизоров —
`armeabi-v7a.apk`, для 64-битных ARM — `arm64-v8a.apk`.
Пакет: `org.smarttube.stable`, versionCode: `2459`.
При совпадении подписей APK устанавливается поверх предыдущей VOT-сборки.

## Как пользоваться

**Видео:** откройте иностранный ролик, нажмите OK и выберите кнопку закадрового
перевода. Долгое нажатие открывает параметры громкости и автоперевода.

**Комментарии:** откройте комментарии к видео. Иностранные сообщения и ответы
переводятся на русский автоматически. Переключатель **Перевод комментариев (RU)**
находится в **Настройки → Плеер → Живые голоса**. После его выключения заново
откройте комментарии, чтобы читать оригиналы.

Озвучка работает через Яндекс VOT, комментарии — через Google Translate.
При сбое перевода комментариев сохраняется исходный текст. Обе функции требуют
доступа к соответствующим внешним сервисам.
